Build a production-ready foundation for a Ride Sharing / Shared Taxi Web App (PWA) focused on local routes such as:

- Dai Loc → Da Nang
- Da Nang → Dai Loc

Business model:
- Shared rides.
- Default price: 90,000 VND per passenger.
- Vehicle types:
  - 4-seat vehicle
  - 7-seat vehicle
- Admin can manually create trips.
- Future AI agents will automatically group passengers and optimize routes.

The goal is to create a modern Web App that behaves like a mobile application without building native Android/iOS apps.
